# Florida Lawn Watering Calculator

This week's lawn watering plan for a Florida city, from
[Waves Pest Control & Lawn Care](https://www.wavespestcontrol.com/). It counts the last
7 days of measured rain, the week's forecast and the local watering limit, and it
answers in minutes per zone.

The card on this page is the free embeddable widget from the
[Lawn Watering Calculator](https://www.wavespestcontrol.com/tools/lawn-watering-calculator/).
It calls the free Waves public API (no key, open CORS). It is a weather-based estimate;
your local watering rules always come first.
