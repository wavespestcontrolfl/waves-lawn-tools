Cycle-and-soak sprinkler planner

When water starts running off a slope or pooling on the soil, stop the sprinkler. If the zone still needs water after it soaks in, use this planner to split the remaining watering into shorter runs.

Plan one zone

Use whole minutes. Keep the entire schedule inside your permitted watering window.

Use the time you already intend to apply to this zone. Subtract any minutes you ran it today.

Use a whole-minute run you observed the soil absorb. If runoff started at minute 9, try 8 or less.

Use the break this zone needs before it can take more water. One uninterrupted run needs no break.

A worked example

A zone needs 22 minutes of watering. It can absorb 8 minutes at a time and needs 15 minutes to soak between runs.

Run it for 8, 7 and 7 minutes. Start at minutes 0, 23 and 45. The last run ends at minute 52. The sprinkler stays off for 30 of those minutes.

To work it out by hand, divide the total by the longest run and round the number of runs up. Spread the watering minutes evenly across those runs, then add a break between each pair.
